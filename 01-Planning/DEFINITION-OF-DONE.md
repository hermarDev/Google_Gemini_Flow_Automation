# Definition of Ready and Definition of Done

## Ready

- [ ] Ticket explains exactly one independently testable outcome.
- [ ] Dependencies and owner identified; required earlier tickets verified.
- [ ] Acceptance tests and negative case described.
- [ ] Model/credits/permissions/privacy impact checked if applicable.
- [ ] Reproduction/evidence source available, or task is a research ticket to obtain it.

## Done

- [ ] Scope and all acceptance criteria met (no hidden expansion).
- [ ] A test was added or a reproducible research artifact supplied.
- [ ] Lint, type checks, fixture tests and relevant e2e/manual tests passed or skipped honestly with reason.
- [ ] UI matches reviewed design system and accessibility requirements when applicable.
- [ ] Security review completed for new host permissions, storage, messages, downloads or provider interactions.
- [ ] Google UI model/duration/output count is revalidated before any paid action.
- [ ] Documentation and ticket work log updated with actual files/commit/test results and limitations.
- [ ] Independent code review / QA accepted, and status is now `done`.

**Not Done:** Agent says complete; code compiles but no behavior test; download started but not completed; model selected only in our own UI; account feature not accessible; paid test skipped but reported passed.
